## 我关注的事情

- **从真实需求出发**：工具应当能融入日常使用，让记录、创作和查找更顺手。
- **把设计决定讲清楚**：不仅展示功能，也说明数据如何保存、权限如何划分、异常如何恢复。
- **用证据说明进展**：区分已实现、已验证和仍待确认的部分，记录版本与测试范围。

这些项目采用 AI 辅助开发。我负责需求定义、使用体验与迭代决策，并结合使用反馈推进验证与改进。各项目展示页说明了具体设计和验证边界。
